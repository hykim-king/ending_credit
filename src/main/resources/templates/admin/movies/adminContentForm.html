    이미지 주소는 어떻게 넣나요?

    1. themoviedb.org에서 해당 영화의 상세 화면으로 들어갑니다.
    2. 원하는 포스터나 스틸 이미지를 마우스 오른쪽 눌러 이미지를 새 탭에서 열기로 엽니다.
    3. 주소창의 image.tmdb.org/t/p/original/abc123.jpg를 복사해 그대로 붙여 넣습니다.

    전체 URL 대신 /abc123.jpg 같은 TMDB 경로만 넣어도 되고, 다른 사이트의 이미지 주소도 그대로 씁니다. TMDB 전체 URL은 저장할 때 경로로 줄여 담습니다.

    TMDB 영화 ID는 어디서 받나요?

    1. themoviedb.org에서 등록할 영화를 검색해 상세 화면으로 들어갑니다.
    2. 주소창이 themoviedb.org/movie/157336-interstellar 형태가 됩니다.
    3. /movie/ 바로 뒤의 숫자 157336이 영화 ID입니다. 뒤에 붙은 제목은 빼고 숫자만 넣습니다.

    포스터·배경 이미지 주소도 같은 상세 화면에서 이미지를 열어 주소를 복사해 오면 됩니다.
